Alur Eksekusi: Pengguna mengakses URL publik melalui HTTPS ke Vercel Edge Network untuk mengunduh antarmuka web. Selanjutnya, Firebase SDK di sisi klien membuka koneksi persisten terenkripsi langsung ke Cloud Firestore untuk operasi CRUD (Create, Read, Update, Delete) secara real-time tanpa perlu mengelola server VM manual.

1

Identifikasi Model Layanan Cloud

Aplikasi ini menggunakan kombinasi model PaaS (Platform as a Service) dan BaaS (Backend as a Service):

  • Vercel (PaaS / Edge Hosting): Menyediakan platform deployment otomatis dari kode sumber ke jaringan CDN global lengkap dengan sertifikat SSL/TLS tanpa konfigurasi OS atau web server (Nginx/Apache).
  • Google Firebase Firestore & Auth (BaaS): Menyediakan database NoSQL terkelola dan autentikasi siap pakai melalui SDK.
  • Alasan Pemilihan: Mempercepat pengembangan, bebas biaya pemeliharaan infrastruktur (serverless), serta memiliki skalabilitas otomatis.
2

Identifikasi Komponen Cloud

  • Komputasi (Compute): Serverless Edge Execution di Vercel untuk mendistribusikan aset aplikasi dan eksekusi logika client-side pada browser pengguna.
  • Penyimpanan Data (Storage): Cloud Firestore (NoSQL Document Database) menyimpan koleksi data perangkat (nama, kategori, MAC/SN, lokasi rak, status, dan peminjam) secara persisten.
  • Jaringan (Networking): Anycast Global CDN, DNS routing otomatis, protokol HTTPS (port 443), dan WebSocket real-time listener (onSnapshot).
3

Analisis Kebutuhan Aplikasi

  • Target Pengguna: Kepala Laboratorium, Asisten Praktikum (Laboran), Dosen pengampu mata kuliah jaringan/IoT, serta mahasiswa peminjam alat.
  • Jenis Data yang Diolah: Data terstruktur/semi-terstruktur berupa identitas perangkat keras (Router, Switch, AP, ESP32, Sensor, Kabel), nomor seri/MAC, lokasi rak, dan log status peminjaman.
  • Perkiraan Beban Pengguna: Rata-rata 10–40 pengguna aktif harian (saat jam praktikum berlangsung) dengan ukuran dokumen kecil (< 1 KB per perangkat).
4

Analisis Kapasitas, Biaya & Skala 100 User

  • Paket & Biaya: Menggunakan paket gratis (Free Tier / Spark Plan) dengan biaya Rp 0/bulan. Batas Firebase Spark: 1 GiB penyimpanan, 50.000 operasi baca/hari, 20.000 tulis/hari. Vercel Hobby: 100 GB bandwidth/bulan.
  • Simulasi 100 Pengguna Bersamaan: Jika 100 user mengakses bersamaan dan melakukan rata-rata 15 kali baca/filter, total operasi hanya ~1.500 reads (masih 3% dari kuota harian 50.000 reads). Aplikasi tetap berjalan lancar tanpa downtime berkat elastisitas otomatis cloud.
5

Evaluasi & Perbandingan Platform Cloud

Perbandingan arsitektur terpilih (Vercel + Firebase) vs Alternatif (AWS EC2 IaaS & Render + PostgreSQL)
